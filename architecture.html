Cryptographic path (dashed)

Interview talking points

  • Fail-closed: any error or unknown state → reject. Never silently approve.
  • Ed25519: mandate fields hashed with sort_keys=True for deterministic bytes; any DB tamper breaks the signature (check ③).
  • Consume-before-payment: mandate marked consumed before Razorpay call → at-most-once guarantee even if gateway crashes.
  • Prompt injection proof: guardrail decisions are numeric (cap check) — it never reads free text from product descriptions.
  • Adversarial TDD: 10 attack tests written BEFORE the guardrail code; guardrail built to pass them.

Shared summary path (dashed)

Interview talking points

  • Two-agent separation: same model grading its own work in one call = self-critique bias. Critic starts fresh, blank context, skeptical persona.
  • JSON schema enforcement: output_config.format.type="json_schema" constrains shape; retry with CLARIFY_SUFFIX handles truncation/refusal.
  • Summary not raw data: LLM sees pre-computed aggregates (pandas), not 10k rows — cheaper, more accurate, scales to any size.
  • Verdict logic: unknown verdict → downgrade (never approve); downgrade caps confidence at 0.5; rejected → dropped entirely.
  • Multi-LLM routing: Claude (paid) / Ollama (free local) / Groq (free hosted) — same pipeline, adapter in config.py.
ML pipeline (generate → train → models)
API / storage
Scoring / SHAP utils
Auth / security

Interview talking points

  • Thesis: behavioral features (payment consistency, income volatility, debt trend) help applicants a traditional credit score would reject — the "decision flip".
  • AUC-PR not AUC-ROC: 95:5 class imbalance; ROC is misleadingly optimistic; AUC-PR (average precision) correctly penalizes false positives on the rare positive class.
  • scale_pos_weight ~19: neg/pos tells XGBoost the class imbalance; without it, the model defaults to predicting 0 (no default) always.
  • No leakage: StandardScaler inside sklearn Pipeline → fitted on train only; stratify=y keeps class ratio in both splits.
  • SHAP in probability space: value reads directly as "+N% default risk" — stakeholder-friendly.
